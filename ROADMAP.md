# Public roadmap epoch

Public development starts from a reviewed source snapshot with a new Git history and a new evidence
ledger. The product's prior technical rationale remains in its public design documents, while
confidential research, pilot observations and the pre-public plan stay in the private maintainer
repository.

The live plan under `aplan/` is the source of truth. `A2-001` owns qualification of the imported
baseline, and `A2-002` owns the first public re-audit of dependency admissions whose private task
citations could not cross the boundary. Subsequent public work is added to that plan before
implementation.
