# Public aplan plan epoch

This directory is the evidence-gated plan for public development. It begins at the sanitized
repository import: the confidential pre-public task ledger, pilot observations, research and
internal evaluation records remain in the private maintainer repository.

`A2-001` qualifies the imported baseline using only public evidence. New technical work is written
here before implementation, with self-contained reasoning that does not require access to the
private history.

On 2026-11-18 the open pre-public backlog and every open issue moved here (`A2-019`), so this plan
is the only place product work is tracked. `ROADMAP.md` explains the cut order.
