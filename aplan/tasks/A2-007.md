## Why

The sanitized public import retained a 16,785-word README whose current guidance still says the
repository is private and whose transformed documentation index points at confidential documents
that are not in the public tree. It also duplicates the complete rule, command and configuration
catalogues, forcing tests to keep the package landing page exhaustive instead of readable.

The cutover left the same stale premise in the CI adoption guide, contributor guide, workflow
comments and terminal portability evidence. It also treated the current tree as the privacy
boundary even though release tags and pull-request refs retained omitted material. Reconcile the
public technical record, rebuild every reachable public ref, and keep detailed executable guidance
in focused public documents.

## Acceptance criteria

- [x] `README.md` is at most 500 words, plain ASCII, and accurately states the latest release,
      development version, supported installation paths, core evidence loop, Action, TUI and MCP
- [x] the first-plan recipe moves to a focused quick-start document and its exact YAML and output
      remain executable tests rather than unchecked examples
- [x] rule and command completeness tests read the canonical rule catalogue and HLD CLI table;
      the README does not duplicate either exhaustive inventory
- [x] current public guidance no longer says `asamarts/aplan` is private or that public CI is a
      future state, and the retired cross-account token workaround is replaced by the public Action
- [x] terminal portability guidance says what has and has not actually run after publication,
      without converting an available workflow into an observed pass
- [x] broken local README links, transformed confidential-document placeholders and stale rule
      counts are absent
- [x] every public branch, tag, release source archive and pull-request ref is derived from the
      sanitized technical record; the superseded public repository is retained only as a private
      recovery archive
- [x] the complete local profile and protected public pull-request checks pass

## Merge durability

The protected public merge rewrites branch commits to keep `main` linear, so a branch-local commit
citation would become unreachable immediately after merge. The four executable test citations are
the durable evidence and remain attached. `docs/design/evolution.md` is intentionally absent and is
audited as a forbidden historical path by the declared history-audit script and publication test;
it is not a current file this task can own, so it is not listed in `paths`.
