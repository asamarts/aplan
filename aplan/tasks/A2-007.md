## Why

The sanitized public import retained a 16,785-word README whose current guidance still says the
repository is private and whose transformed documentation index points at confidential documents
that are not in the public tree. It also duplicates the complete rule, command and configuration
catalogues, forcing tests to keep the package landing page exhaustive instead of readable.

The cutover left the same stale premise in the CI adoption guide, contributor guide, workflow
comments and terminal portability evidence. Reconcile those current surfaces without rewriting
historical changelog, ADR or pilot records, and keep detailed executable guidance in focused public
documents.

## Acceptance criteria

- [ ] `README.md` is at most 500 words, plain ASCII, and accurately states the latest release,
      development version, supported installation paths, core evidence loop, Action, TUI and MCP
- [ ] the first-plan recipe moves to a focused quick-start document and its exact YAML and output
      remain executable tests rather than unchecked examples
- [ ] rule and command completeness tests read the canonical rule catalogue and HLD CLI table;
      the README does not duplicate either exhaustive inventory
- [ ] current public guidance no longer says `asamarts/aplan` is private or that public CI is a
      future state, and the retired cross-account token workaround is replaced by the public Action
- [ ] terminal portability guidance says what has and has not actually run after publication,
      without converting an available workflow into an observed pass
- [ ] broken local README links, transformed confidential-document placeholders and stale rule
      counts are absent
- [ ] the complete local profile and protected public pull-request checks pass
