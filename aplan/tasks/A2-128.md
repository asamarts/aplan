## Why

One adopting repository reached 282 advisory warnings, 259 of them `APLAN009`. The human report
printed a small prefix, "280 further finding(s)", and one aggregate warning count. Its machine
formats were complete and mutually consistent, but a person needed to emit agent output and write
a script to learn that one rule dominated the baseline. A newly introduced warning is therefore
difficult to distinguish from the standing population at the default interface.

This is not permission to make a large warning baseline acceptable: the adopter owns reducing it.
It is a reporting gap that applies anywhere diagnostics are suppressed for readability. Give the
human reader a compact, deterministic inventory by severity and rule code so that the visible
summary reconciles with the full report, rare findings remain conspicuous, and an agent can quote
a useful overview without switching to a machine format. Keep JSON, agent, GitHub and SARIF
contracts unchanged; they already carry every finding.

## Acceptance criteria

- [ ] human `check` and `verify` output groups every finding by severity and rule code, with exact
      counts that sum to the existing verdict totals even when the detailed list is truncated
- [ ] the compact inventory makes a rare or newly added rule visible behind a dominant baseline
      without requiring `--format agent`, JSON parsing or terminal colour
- [ ] ordering is deterministic, singular/plural wording is correct, and zero, one and many rule
      codes are covered, including a report containing both errors and warnings
- [ ] the summary does not duplicate the full finding prose or make an advisory warning sound like
      a denied verdict; the existing task count, suppression notice and structural/evidence scope
      notes remain accurate
- [ ] all human diagnostic writers share one implementation, while JSON, agent, GitHub and SARIF
      bytes and schemas remain unchanged
- [ ] the change to the existing diagnostic rendering has a `Behaviour` with a regression proof,
      plus changelog and upgrading guidance for consumers that scrape the old human footer
