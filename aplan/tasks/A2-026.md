## Why

Reported in #33 (item 1). `check-docs` promises to check that a document names tasks that
exist, but it only recognises ids that carry digits. A document naming `` `ABC-999` `` is
reported; `` `M-oen` `` (a typo of the milestone `M-one`) and a release id such as `R-v9` pass.
The shapes of the ids a plan actually uses are known from the plan, so a backticked token can
be matched against them.

## Acceptance criteria

- [ ] a backticked token shaped like one of the plan's own id conventions, including milestone and
      release ids without digits, is checked against the plan
- [ ] an unknown id of such a shape is reported with a did-you-mean when a close match exists
- [ ] ordinary backticked words that match no id convention are not reported
- [ ] #33 item 1 is ticked on the issue
