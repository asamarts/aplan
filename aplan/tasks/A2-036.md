## Why

Reported in #33 (item 5). Tasks move between cuts with `aplan mv` and edges change with
`aplan dep`, but a release's `contains` can change only by editing the file.
`aplan dep rm --after M-one R-a` is refused with `APLAN047`, whose fix text says to "move the
id to `blocked_by` alone" without saying how.

## Acceptance criteria

- [ ] a guarded command adds and removes `contains` entries with the same validation as a hand edit
- [ ] `APLAN047`'s fix text names that command
- [ ] #33 item 5 is ticked on the issue
