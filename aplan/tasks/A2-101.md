## Why

After one adopting repository renamed one source file, thirteen tasks still named the old path.
Seven were terminal and correctly preserved the historical path their evidence resolves against.
Six were live and had become uncloseable: a future commit touching the new name would overlap none
of their declared territory. `check` and `verify` stayed green because live tasks had no citation
to resolve.

In miniature: `ABC-001` (`done`) and `ABC-002` (`todo`) both list `src/old.rs`, and a commit
renames it to `src/new.rs`. `ABC-001` must keep `src/old.rs`; a future commit touching
`src/new.rs` overlaps none of `ABC-002`'s declared territory, and nothing says so.

The status split makes a blind repository-wide rewrite unsafe. A supported repair must preserve
terminal history while retargeting only live claims, and an early diagnostic must distinguish a
literal path that disappeared from a prospective glob that has not been created yet.

## Acceptance criteria

- [x] implements `ADR-0071` (`A2-056`): a repository-aware `verify` report identifies live literal
      `paths` entries whose tracked target was renamed or removed in Git history, as well as live
      literal `paths` entries naming an existing tracked directory (`src` when `src/**` is tracked),
      without applying those checks to terminal historical tasks or warning on never-tracked
      prospective files
- [x] a checked retarget operation rewrites matching live tasks atomically and refuses to alter
      terminal tasks unless a separate, explicit historical migration is designed
- [x] glob patterns, never-tracked prospective literal paths, and revision-aware terminal resolution
      are not reduced to a current-filesystem existence check
- [x] rename detection and ambiguity are deterministic, bounded and reported rather than guessed
- [x] tests cover one old path shared by live and done tasks, a bare tracked directory on a `todo`
      task, a glob that still matches, a never-tracked prospective literal path, and a rename with
      more than one candidate
