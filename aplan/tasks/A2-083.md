## Why

`aplan export-agents-md --check` fails with *"a value is required for '--check <FILE>'"*. The
help describes it as *"`--check` fails when the file disagrees"*, which reads as a mode rather than
as taking a path; `--write` in the same command does take one, so the symmetry is defensible and
the prose is what misleads.

Thirty seconds lost in one adopting repository. Filed rather than declined because "not worth the
cost" is a claim about how many adopters read the help the same way, and this project's own review
of past declines found cost-based declines overturned three times in five.

## Acceptance criteria

- [ ] the help makes clear that `--check` takes the file to check
- [ ] or `--check` with no value checks the conventional path, and the help says which
