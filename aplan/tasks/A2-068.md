## Why

One adopting repository rewrapped its `AGENTS.md` to 100 columns. The generated block broke and
`--check` caught it, which is the point. What was not obvious from the documentation: the exit
code is `0` for prose changed *outside* the markers and `1` only for drift inside them.

That is the correct shape for a file whose whole design is "the repository keeps its own prose
around a generated block". But the flag's help says it "fails when the file disagrees", and a
first-time reader reasonably assumes that means the file is unchanged. The adopter recorded the
doubt so the next reader could resolve it without reading the source; the help should resolve it
instead, which is the state this task exists to reach.

## Acceptance criteria

- [ ] the help for `--check` says what it compares, so a reader knows prose outside the
      markers is theirs to change
