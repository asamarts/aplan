## Why

When a mutating command such as `aplan close` refuses because its pre-write gate returns multiple
findings, the human diagnostic renderer (`crates/aplan-output/src/lib.rs`) suppresses repeated fix
lines and prints:

```text
(1 further finding(s) carry their own fix; `--format agent` prints every one)
```

`aplan close` does not accept `--format`; passing `--format agent` fails with
`error: unexpected argument '--format' found`. The hint is true for `check` and `verify`, not for
a mutation command that renders an internal gate report before refusing.

## Acceptance criteria

- [x] a refused mutation command that does not accept `--format` never prints advice to pass
      `--format agent`
- [x] either every suppressed finding's fix is shown on refused mutations, or the footer names a
      command that actually accepts `--format agent` (such as `aplan verify --format agent`), and
      the choice is covered consistently across all refusing mutation commands
- [x] `check` and `verify` human output keep their existing `--format agent` hint
- [x] regression tests verify that refusing `close` with multiple findings emits no invalid
      `--format agent` flag advice
