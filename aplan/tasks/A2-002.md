## Why

The imported dependency policy describes valid technical admissions, but its historical task
citations belong to the private planning epoch and cannot serve as public evidence. Re-run the
dependency census, license and advisory checks, binary-size measurement, and terminal-stack audit
from the public repository. Replace this single import-boundary owner with public tasks wherever
the review identifies independently changeable work.

## Acceptance criteria

- [x] every admitted dependency is present at the declared kind and target and has a current need
- [x] license, source, advisory, duplicate and forbidden-progress-package gates pass
- [x] native default and headless release binaries are remeasured with the public toolchain
- [x] any follow-up is split into public tasks before this import-boundary task is closed

## Audit disposition

The 2026-11-03 public audit found 288 locked packages, 200 default product packages, 169 headless
product packages, and a 31-package TUI increment. Cargo-deny passed advisories, bans, licenses and
sources. Separate Rust 1.99.1 release builds from public control revision `51a5c95` produced a
2,397,808-byte TUI increment, or 12.43 percent, below the 2.5 MB and 15 percent ceilings. The six
exact duplicate exceptions remain unavoidable transitive version splits and every recorded direct
admission still has a source use.

Two unused historical binary fields were removed because they did not participate in any verdict.
`A2-009` now owns the independently changeable safe Rust YAML parser cutover and records its current
external blockers. No other follow-up was identified.
