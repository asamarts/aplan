## Why

The imported dependency policy describes valid technical admissions, but its historical task
citations belong to the private planning epoch and cannot serve as public evidence. Re-run the
dependency census, license and advisory checks, binary-size measurement, and terminal-stack audit
from the public repository. Replace this single import-boundary owner with public tasks wherever
the review identifies independently changeable work.

## Acceptance criteria

- [ ] every admitted dependency is present at the declared kind and target and has a current need
- [ ] license, source, advisory, duplicate and forbidden-progress-package gates pass
- [ ] native default and headless release binaries are remeasured with the public toolchain
- [ ] any follow-up is split into public tasks before this import-boundary task is closed
