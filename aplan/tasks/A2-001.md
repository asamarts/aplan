## Why

Public development begins from a reviewed source snapshot, not from the confidential repository's
historical commits or evidence ledger. Re-run the complete hosted validation profile against the
new repository identity, then close this task with evidence rooted only in public commits and
publicly reproducible tests.

This task is the explicit epoch boundary. Earlier implementation records remain in the private
maintainer repository; they are not evidence for work performed after this import.

## Acceptance criteria

- [ ] the complete hosted repository profile passes from an unauthenticated fresh clone
- [ ] the release action self-test and retained release downloads pass through the public name
- [ ] closure cites only commits and tests reachable and reproducible from the public repository
