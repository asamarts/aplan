## Why

A post-delivery audit of `A2-022`, `A2-178` and `A2-027` found five edge-case gaps across the CLI,
output, TUI review and Action download helper:

- **Refused `--format agent` inbox promotions emitted a contradictory `agent_instruction`
  (`A2-022`).** `render_capture_action` checked only `report.task_id.is_some()` and instructed
  agents to `"Use the reported full capture id and task id for later machine requests"` even when
  `outcome` was `refused` and no task was created.
- **Late `CommitOutcome::Denied` in `finish_capture_promotion_with` did not refresh `publishable`
  or `findings` (`A2-022`).** It matched `CommitOutcome::Denied(_)` without binding the returned
  `ChangeSet`, leaving `report.publishable` and `report.findings` at their pre-commit preview
  values if a late refusal occurred.
- **TUI promotion review rows reported `Capture state after preview: promoted` even when the
  promotion preview was denied (`A2-022`).** `crates/aplan-tui/src/inbox.rs::review_rows` rendered
  the predicted promoted state and atomic publication message regardless of `ChangeDisposition`.
- **A static progress unit test bypassed `ever_painted` (`A2-178`).**
  `progress_renderer_control_messages_acknowledge_and_restore_rows` hand-mutated
  `static_row.row = ProgressRowState::Painted` without setting `ever_painted = true`, silently
  skipping the static `Stop` `"interrupted"` branch.
- **Action download retry helper edge cases (`A2-027`).** `ci/scripts/download-action-release.sh`
  treated an explicit empty `APLAN_DOWNLOAD_BACKOFF_SECONDS=""` as unset (`:-` instead of `-`),
  expanded `"${delays[@]}"` without an empty-array guard for Bash <4.4 under `set -u`, and did not
  classify `gh`'s `"error connecting to"` / `"failed to connect"` connectivity wrapper messages as
  transient.

## Acceptance criteria

- [x] refused `inbox promote --format agent` emits a refusal instruction stating that nothing was
      written and the reported task id was not created, pinned by both `aplan-output` unit tests
      and `capture_inbox::refused_inbox_promotion_reports_open_state_for_dry_run_and_apply`
- [x] `finish_capture_promotion_with` updates `publishable = false` and `findings` from the denied
      `ChangeSet`, pinned by a unit test exercising an injected `CommitOutcome::Denied`
- [x] TUI `inbox::review_rows` reports the real `open` state and `Would become: promoted` for a
      denied promotion preview, pinned by a unit test in `aplan-tui`
- [x] `progress_renderer_control_messages_acknowledge_and_restore_rows` sets `ever_painted = true`
      (or paints via `draw_active`) so the static `Stop` interrupted write path stays exercised
- [x] `ci/scripts/download-action-release.sh` honours empty `APLAN_DOWNLOAD_BACKOFF_SECONDS=""`
      safely under `set -u`, classifies `"error connecting to"` / `"failed to connect"` as
      transient, passes `shellcheck`, and is pinned by `xtask` integration tests
