## Why

Feature completion is a claim. The last task reruns the programme's architectural, parity,
usability, performance, portability and dependency evidence as one stable-release argument.
Repository visibility is deliberately not evidence for that product claim: publishing the
repository does not mean the TUI quality cut is complete.

## Acceptance criteria

- [ ] every current command has its executable TUI disposition and every promised native action has
      end-to-end coverage
- [ ] no TUI path parses rendered CLI output, writes task files directly or implements a weaker
      verdict
- [ ] CLI and TUI graph views derive from one typed graph workspace and explicit complete/windowed
      projection contract, account for every admitted or omitted node and edge, preserve meaning
      without color and meet the recorded comprehension and scale evidence
- [ ] startup and every slow-capable command have a truthful progress disposition; disabled and
      machine modes remain byte-stable and all phase/animation workers terminate on every exit path
- [ ] task summaries retain exact values through semantic visual hierarchy, and every supported
      narrow/short layout completes the representative read and mutation journeys
- [ ] overlay pointer targets agree with painted semantic controls and cannot bypass mutation
      activation, confirmation, focus or topmost-layer policy
- [ ] all snapshot, reducer, parity, PTY, performance, portability, coverage and workspace gates
      pass from a clean tree
- [ ] open usability findings are either release blockers or explicitly scheduled with evidence that
      the stable-release bar still holds
- [ ] terminal restoration and stale-mutation fault matrices are rerun against the release candidate
- [ ] documentation, dependency inventory and measured build identity describe the exact candidate
      reviewed
- [ ] the live dependency graph keeps the workflow ergonomics release audit (`A2-117`) behind
      `M-tui-quality`, with a test that fails if that product-qualification path is removed or
      bypassed
