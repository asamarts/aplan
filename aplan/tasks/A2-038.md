## Why

Reported in #34. Type errors in the runner configuration name no key
(`invalid type: string "true", expected a sequence`, `expected struct TestSchedule`), and
another names `test.run`, which is not a key (`aplan facts` lists `test.runners.run`).

## Acceptance criteria

- [ ] every runner configuration type error names its full key path and the expected shape, for
      example `test.schedule: expected a mapping such as {capacity: 1}`
- [ ] no error names a key that does not exist
