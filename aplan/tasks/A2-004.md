## Why

The public import intentionally begins a new A2 plan epoch with no task claiming the `untestable`
exemption. The policy audit recognized that state only while there were no closed tasks, so closing
the qualification and coverage-stability tasks made the development profile fail even though both
tasks cite tests. The exception belongs to the exemption-free A2 epoch, not to an empty closed-task
set.

## Acceptance criteria

- [x] the exemption audit accepts an A2-only public plan with test-backed closed tasks and no
      `untestable` claims
- [x] the audit still refuses an exemption-free plan outside the explicit A2 epoch
- [x] once an `untestable` claim exists, it remains a strict minority of closed work
