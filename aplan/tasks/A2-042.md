## Why

Reported in #19. `aplan close --evidence note:...` and `amend --add-evidence note:...` are
refused because a note needs a `captured` date that the tool will not invent, and the message
sends the user to edit the file by hand, outside the commands that validate a citation. An
earlier decision kept notes unrecordable through the CLI. The report proposes
`--captured YYYY-MM-DD`, supplied by the caller, so nothing is read from the clock.

Untestable: a decision record.

## Acceptance criteria

- [ ] a decision is recorded on whether `close` and `amend` accept a caller-supplied captured date for
      note evidence, superseding the earlier decision if it changes
- [ ] the implementation task's criteria match the decision, or it is dropped with the reason
