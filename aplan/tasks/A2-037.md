## Why

Reported in #34. Writing `test.runners` by hand reveals its requirements one refusal at a
time: a small valid configuration takes seven attempts. The report quotes `missing field
schedule`; since the parser switch (`A2-009`) it reads `` test: missing field `schedule` ``, which
names the parent but still one field per attempt. A `schedule` key on a runner is reported as
unknown and then still missing, and nothing says it belongs one level up.

## Acceptance criteria

- [x] one error lists every missing field with its full path, for example `test.schedule`,
      `test.runners[0].list` and `test.runners[0].run`
- [x] a misplaced key names where it belongs
- [x] a test reproduces the sequence from #34 and reaches a valid configuration in one step
