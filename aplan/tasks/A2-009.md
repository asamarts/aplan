## Why

The public dependency re-audit confirmed that the current YAML bridge is maintained and free of a
known advisory, but its parser remains C source translated to unsafe Rust. The private-era
qualification of the intended safe Rust backend found real compatibility and licensing blockers,
so that unfinished hardening work needs a public owner and a new qualification against an
immutable, licensed release.

## External prerequisites

The candidate backend must publish an immutable source revision with an explicit license grant,
Rust 1.88 support, and the compatibility fixes recorded in `docs/design/yaml-parser.md`. A moving
branch, sibling checkout, or unlicensed private source is not an admissible product dependency.

**Met (2026-11-17).** `ayaml` is published on crates.io under `MIT OR Apache-2.0` with
`rust-version = "1.88"`. Version 0.1.2 (2026-11-14) added the compatibility entry points with
caller-supplied limits and bounded `%TAG` expansion, and 0.1.3 (2026-11-15) corrected local-tag
reading after a flow `?` in compatibility mode. A maintainer qualification against 0.1.2 already
passed the complete local gate before this task was unblocked. The maintainer decided to target
0.1.3 directly, so only one parser version is qualified in public, consumed through the existing
narrow `yaml_compat` boundary with an exact version pin.

## Acceptance criteria

- [x] an immutable licensed backend passes the complete value, mapping, tag, scalar, location,
      duplicate-key, serialization, and empty-document compatibility contract
- [x] repository fixtures and hostile-input boundaries pass typed and generic differential tests
      without weakening existing assertions
- [x] normal product graphs contain neither `yaml_serde` nor `libyaml-rs`, and license, source,
      advisory, duplicate, MSRV, schema, and release gates pass
- [x] default and headless binary size plus parser-heavy latency remain within their committed
      budgets
- [x] the complete local and hosted validation profiles pass from the same public source revision
