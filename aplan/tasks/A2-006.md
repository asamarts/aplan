## Why

The compiler-free selector was admitted on a private persistent runner because the account could
not start the future standard hosted environment before publication. Now that the public repository
uses `ubuntu-latest`, run the canonical clean-source harness on that exact production runner shape
and retain the observation beside the selector decision. This is an observational compatibility
check, not a timing assertion in ordinary CI.

## Acceptance criteria

- [x] seven samples against one immutable public `main` commit report a stable output digest,
      stable Git process count, and zero Cargo and rustc processes
- [x] the hosted warm p95 is below one second and the cache-free p95 is below five seconds
- [x] the ordinary public development workflow passes the same source revision
- [x] the design record names the public run and job, runner environment, source and harness
      digests, timing distribution, and compatibility conclusion
- [x] the final candidate retains no temporary measurement workflow; its external-fork branch is
      deleted immediately after merge
