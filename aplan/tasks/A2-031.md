## Why

Reported in #32 (item 2). `aplan ready` lists an `in_progress` task exactly like a `todo` one,
so an agent choosing work cannot see what is already started, and the JSON rows carry no
status at all.

## Acceptance criteria

- [ ] human `ready` marks a started task, for example `ABC-001 [in_progress]`
- [ ] `ready --format json` rows carry a `status` field, and the schema change is versioned as the
      output contract requires
- [ ] what `ready` computes is unchanged
- [ ] a comment on #32 records item 2 done, citing this task
