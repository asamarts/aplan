## Why

A full post-merge audit and `ci/scripts/preflight.sh --full` run over the delivered Phase 2
increment (`A2-092`, `A2-119`, `A2-041`, `A2-159`, `A2-037`, `A2-038`, `A2-135`) found four
functional/documentation defects and a seven-crate coverage-floor regression hidden by
development-only PR validation:

1. `Command::Paths` accepted parent-only flags (`--format`, `--repo`, `--sample`, `--cut`, etc.)
   before `match` and silently ignored them (`aplan paths --format json match ...` printed human
   output and exited 0).
2. `CHANGELOG.md` omitted the `A2-092` (`aplan paths match`) feature entry.
3. `relative_under_root` in `aplan-mcp` fell back to `"aplan"` when a plan lived outside the
   repository root instead of preserving the external path as `CompletedWorkspace::from_context`
   does.
4. `tests::a_filtered_complete_test_catalogue_renders_its_counts` (`A2-159`) failed when run on an
   80-column PTY because `format_test_catalogue_human` wraps across lines at terminal width.
5. `completed_history_pty_journey_covers_overview_completed_inspector_and_narrow` (`A2-041`)
   waited only on `Completed: [REC]` after `Enter` and `COMPLETED HISTORY` after `Esc` -- both
   already visible in the wide split-pane view -- so focus transitions raced `resize`/`1` under
   instrumented runs.
6. `tui_evidence_parity::every_task_local_evidence_action_matches_the_complete_cli_post_state`
   compared raw wall-clock `closed_at` timestamps between consecutive CLI and TUI `close` calls,
   flaking whenever the system clock crossed a second boundary.
7. `cargo xtask coverage --check` fell below declared `coverage.json` floors in `aplan-mcp`,
   `aplan-config`, `aplan-output`, `aplan-evidence`, `aplan-core`, `aplan-app`, and `aplan-tui`.

## Acceptance criteria

- [x] `Command::Paths` rejects parent-only flags before `match` with exit 2 instead of silently
      dropping them, covered by an end-to-end test in `crates/aplan/tests/paths.rs`
- [x] `CHANGELOG.md` documents `A2-092` (`aplan paths match`), `relative_under_root` preserves
      external plan roots instead of aliasing `aplan`, and the `A2-159` unit test is independent of
      terminal wrap width
- [x] unit tests exercise the uncovered branches across `aplan-mcp`, `aplan-config`, `aplan-output`,
      `aplan-evidence`, `aplan-core`, `aplan-app`, and `aplan-tui` so `ci/scripts/preflight.sh --full`
      passes all 11 gates green without lowering any `coverage.json` floor
