## Why

The README's **Start** section is the first thing an adopter runs. It said:

```sh
aplan init
aplan add "Define the release gate" --id P1-001 --effort 1 --tag cross-cutting
aplan check
```

`aplan init` writes only `.aplan.yml`, and `aplan add` then refuses with "plan root `aplan` is not
a directory, nothing would be checked". An end-to-end run of the increment found it on
2026-11-18. The block was tested only by handing each line to the argument parser, which accepted
it, so the documented path was never run.

`docs/quickstart.md`'s recipe is already read and run by `crates/aplan/tests/greenfield.rs`; this
holds the README to the same standard. Whether `add` itself should create the plan directory, as
`add --from` handles a fresh plan differently, belongs to `A2-077`.

## Acceptance criteria

- [ ] the README's first-plan block creates the plan directory before the first `add`
- [ ] a test reads the block out of `README.md` and runs each line, in order, in an empty
      directory, and the resulting plan checks clean; it fails on the old block
