## Why

An end-to-end audit of PRs #89-#91 (`e41ca8d..cdb12c5`, delivering `A2-195`, `A2-194`, `A2-193`,
and `A2-122`) identified seven concrete edge-case and end-to-end verification gaps to close before
starting the trace/review correctness track (`A2-051` -> `A2-053`):

1. **Non-string keys under `requires`:** `parse_build_contract` in `crates/aplan-config/src/lib.rs`
   skipped non-string YAML keys via `filter_map(|k| k.as_str())`, letting serde emit a raw error
   instead of an explicit `BadRequires` listing the accepted sub-keys.
2. **Unsorted multiple unknown frontmatter fields:** `unknown_frontmatter_field` in
   `crates/aplan-core/src/load.rs` preserved raw `unexpected` order rather than sorting field names
   deterministically when multiple unknown fields appear in one task.
3. **Mismatched MCP `unconfigured` footer on `requires` refusal:** `AplanServer::dispatch` in
   `crates/aplan-mcp/src/server.rs` appended the unknown-key typo sentence even when the refusal
   was already a `requires` build-contract mismatch.
4. **Missing `Rule::StaleAgentContract` coverage entries for `ADR-0072`:**
   `crates/aplan-e2e/tests/coverage.rs` did not yet drive provenance-only skew (`Silent`) or
   malformed/duplicate provenance (`Fires`) inside the `Rule::ALL` table.
5. **Missing structural report cache round-trip test for `agent_contract_provenance`:**
   `crates/aplan-app/src/store.rs` persisted `agent_contract_provenance` without a dedicated test
   proving disk round-trip fidelity and cross-build cache-key isolation.
6. **Missing end-to-end tests for headless `build.tui`, explicit-root MCP stdio, and `--at`:**
   `crates/aplan/tests/config_error.rs` needed real-binary end-to-end proofs for
   `requires.capabilities: [build.tui]` (default vs `--no-default-features`), explicit-root
   `aplan_check(root: ...)` over stdio MCP, and `aplan summary --at HEAD` against a committed
   failing `requires`.
7. **Missing end-to-end tests for `--format agent`, `verify --format json`, MCP `aplan_verify`, and
   pre-`ADR-0037` absent provenance:** `crates/aplan/tests/agent_contract_drift.rs` needed explicit
   assertions across all four remaining surfaces.

## Acceptance criteria

- [x] `parse_build_contract` explicitly rejects non-string keys under `requires` with a clear
      `BadRequires` message and unit tests cover non-string sub-keys, duplicate sub-keys,
      non-mapping shapes, and duplicate top-level keys
- [x] `unknown_frontmatter_field` sorts multiple unknown fields deterministically with a unit test
- [x] `AplanServer` emits a tailored build-contract refusal footer when unconfigured due to
      `requires`, without appending the unknown-key typo footer
- [x] `crates/aplan-e2e/tests/coverage.rs` includes `ADR-0072` provenance-only (`Silent`) and
      malformed-provenance (`Fires`) scenarios under `Rule::StaleAgentContract`
- [x] `crates/aplan-app/src/store.rs` proves `agent_contract_provenance` cache round-trip and
      checking-build key isolation
- [x] `crates/aplan/tests/config_error.rs` exercises `requires.capabilities: [build.tui]` across
      default and headless builds, explicit-root MCP stdio refusal, and `summary --at HEAD`
- [x] `crates/aplan/tests/agent_contract_drift.rs` exercises `--format agent`,
      `verify --format json`, MCP `aplan_verify`, and pre-`ADR-0037` blocks without provenance
